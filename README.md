📌 Description

A simple console-based Library Management System built in C++ using object-oriented programming. The project manages book details using a Book class and demonstrates different types of constructors along with encapsulation using setters and getters.

⚙️ Features
Create book objects using multiple constructors
Store and display book details (title, author, ID, price)
Copy book objects using copy constructor
Update book data using setters
🧠 Concepts Used

OOP, Classes & Objects, Constructors (Default, Parameterized, Copy, Overloaded), Encapsulation
